02 / 3D workflow

Blender, with an
agent in the loop.

Exploring an agent-assisted 3D pipeline, from a creative brief to visible iteration and engine import.

Role
Workflow direction & visual review
Status
Process study in progress
Tools
Blender · Claude Code · MCP · Unreal
Focus
Iteration · 3D assets · Human QA

The project in a sentence

A practical exploration of directing Blender through an AI agent, using a timber grandstand and helmet crests as test assets.

What this case study shows

A visible progression from Blender blockout to a grandstand placed in an Unreal scene, supported by a ticket-driven workflow and a separate helmet import experiment.

01 / The brief

Make an asset that can be used.

The grandstand needs to read as a convincing piece of a tournament venue, with seating, access and structural framing. It also has to become a practical game asset.

I use the workflow to explore how much of the repetitive 3D work an agent can assist with while I retain the creative brief and visual review. The target is an asset I can inspect and refine through clear stages.

02 / Visible iteration

From blockout to structure.

These screenshots document stages of the asset: blockout, structural development and closer visual detail.

B3D-01 / Project record

A ticket directs the Blender work.

I start by assigning a ticket from the Blender route of my Kanban system. In PowerShell, I ask Claude Code to carry out that task; Claude Code drives Blender through MCP. My contribution is the brief, constraints, review and decisions about the result.

  1. 01Choose the Blender ticket
  2. 02Direct Claude Code
  3. 03Run Blender through MCP
  4. 04Review the asset

This describes my working process. The genuine images above show asset stages; they are not a reconstruction of a particular correction or a claim of manual modelling.

03 / Authorship

Direct the workflow. Inspect the asset.

My part

Define the intended asset, review its shape and suitability, direct revisions and decide what needs further work.

The agent’s part

Assist with Blender operations through MCP. The connection lets the agent work with the scene; the output still needs human inspection.

  1. 01Set the asset brief
  2. 02Build through Blender + MCP
  3. 03Inspect and refine
  4. 04Validate in Unreal

Workflow under study. The last stage requires asset-specific checks before calling a result production-ready.

04 / Engine evidence

Assets in their engine context.

The helmet work provides a visible example of assets moving into an engine. The supplied captures show crest variants and the helmet with separate crest meshes in an Unreal test scene.

B3D-02 / Project record

The grandstand in its Unreal setting.

The developed grandstand is now placed in a built-out Unreal scene. The capture connects the Blender stages to a visible in-engine result: timber framing, covered seating and access structures within the tournament environment.

This is an environment scene, not a playable level. It demonstrates placement and visual integration; walkable collision, performance and export settings have not been validated by this screenshot.

05 / What I take forward

A good-looking viewport is one checkpoint.

The workflow connects a written task to a visible asset and an engine scene. I can direct the work through tickets while retaining the creative brief and visual review. Technical validation is a separate stage when an asset needs to meet a specific gameplay or performance requirement.

Evidence status. Genuine captures show Blender development, helmet import and the grandstand placed in Unreal. This is a workflow and visual-integration study; no production-readiness, geometry-budget or playable-collision result is claimed.
